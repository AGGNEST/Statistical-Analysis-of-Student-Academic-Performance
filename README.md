# Statistical-Analysis-of-Student-Academic-Performance

# Project Overview
This project presents a statistical analysis of student academic performance using a publicly available educational dataset.

The analysis was conducted using (SAS) and includes descriptive statistics, hypothesis testing, correlation analysis, ANOVA, and logistic regression.

# Objectives
The project investigates whether selected academic, demographic, and behavioral variables are associated with student academic outcomes.

# Statistical Methods
* Descriptive Statistics
* Pearson Correlation
* Independent Two-Sample t-Test
* Chi-Square Test of Independence
* One-Way ANOVA
* Tukey HSD
* Binary Logistic Regression

# Dataset
* Observations: 995
* Variables: 12
